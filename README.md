One funny line: the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM.

Run `node main.ts` — it writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), prints it, and self-checks the 1–200 character gate.
